# 大阪大学 接合科学研究所 柴原研究室 ホームページ（制作中）

表示: https://jwri-uo.github.io/shiba-lab/

## 更新のしかた（あらまし）

- **ページを直す**: そのページの `.html` を開き、`<main>` から `</main>` の間を直して push する。
- **お知らせを足す**: `hinagata-news.html` を写して `news-日付.html`（例 `news-20261120.html`。`news-` の後ろは半角の小文字・数字・ハイフンだけ）という名前にし、日付（`2026.11.20` の形）・分類・題名・本文を書いて push する。一覧、トップの新着、前後の記事へのリンク、小さな画像は自動で作られる。記事の最初の写真を替えれば、小さな画像も作り直される。
- **ページを足す**: `hinagata-page.html` を写して好きな名前にし（`news-`・`theme-`・`movies-`・`hinagata-` で始まる名前は使わない）、中身を書く。メニューに出すなら `_frame/menu.txt` に1行足す。
- **メニューを直す**: `_frame/menu.txt` を直す。全ページの上の帯と左のメニューが作り直される。
- **ヘッダーやフッターを直す**: `_frame/frame.html` を直す。

push すると GitHub が自動で `build.py` を実行し、共通部分と一覧を作り直す（数分かかる）。作業の前には必ず pull する（作り直しのたびに GitHub 側に自動のコミットが増えるため）。

## 赤い印が出たら

`build.py` は、直す必要のある所を見つけると、ファイル名と直し方を出して赤い印で終わる。Actions の画面で赤い行を開き、「共通の枠と一覧を作り直す」の段を見る。

- 1つのページの問題（自動の目印が崩れた、UTF-8 でない、など）は、そのページだけ前のままにして、ほかのページは作り直す。
- お知らせの問題（日付が読めない、ひな形の見本が残っている、ファイル名の決まり違反、など）があるあいだは、記事が一覧から消えないように、お知らせの一覧・トップの新着・前後の記事・研究テーマの関連も前のままにする。
- 出ているファイルを全部直して push すると、次の実行が緑になる（自分が触っていないファイルが出ていることもある）。
- 枠（`_frame/frame.html`）やメニュー（`_frame/menu.txt`）の問題は全ページに響くので、何も書き換えずに止まる。
- 「送り直しても入らなかった」と出たときは、Actions の画面の「サイトの自動生成」から Run workflow を押す。

結果は、Actions の画面の左で「サイトの自動生成」を選び、一番上の行で確かめる。コミットの一覧の✓と×では判断しない（自分のコミットには公開の取り消しで×が付くことがあり、bot のコミットには作り直しの結果が付かない）。続けて push すると、待ちの古い回は灰色の「取り消し」になるが、最後の回が全体を作り直すので気にしなくてよい。bot の Rebuild のコミットの後に「pages build and deployment」が出ないときは、その前の公開の行を Re-run する。

`build.py` の終了コード: 0 は問題なし、2 は直す必要のある所あり（作り直せた分は反映する）、1 は枠やメニューの問題か思わぬエラー（何も反映しない）。

## 置いてあるもの

| 場所 | 中身 |
|---|---|
| `*.html` | ページ。お知らせは `news-〜.html`、研究テーマは `theme-〜.html` |
| `_frame/frame.html` | 全ページ共通の枠（ヘッダー・フッター） |
| `_frame/menu.txt` | 上の帯と左のメニューの定義 |
| `build.py` | 共通部分と一覧を作り直すスクリプト |
| `_guide/` | 先生向けの手順書（お知らせとトップの写真・動画の入れ方の PDF）、トップの写真の型（8:3）、「メニューの左」の背景を作る `背景を作る.py` |
| `img/` | 画像 |
| `files/` | PDF・動画・元の大きさの写真（1個100MB未満。動画は1本50MBくらいまで） |
| `css/` `js/` `vendor/` | 見た目と動きの部品 |

`<!-- 自動:〜 -->` と `<!-- /自動:〜 -->` に挟まれた所は自動で作り直されるので、手で直しても元に戻る。目印そのものは消したり変えたりしない。研究テーマの `<!-- 自動:関連 言葉|言葉 -->` の言葉は半角の `|` で区切る。記号もそのままの文字として探す（`(?` で始まる言葉だけは式として使う。theme-04 の AI の所）。

ページの `<head>` の中で、そのページだけで読み込む行（`js` など）は `<!-- この下は、このページだけの行 -->` より下に書く。それより上は枠の行で、作り直すと `_frame/frame.html` のとおりに戻る。

`img/` の `ns-〜.jpg` と `nt-〜.jpg` は、お知らせの小さな画像として自動で作り、使われなくなれば自動で消す。ほかの画像の名前を `ns-` や `nt-` で始めない。

## 設定（`build.py` の頭にある）

| 名前 | 意味 |
|---|---|
| `SITE_URL` | サイトの場所。別のサーバーや独自ドメインへ移したら直す |
| `SEARCH` | 検索に出すか。`False` の間は全ページに検索よけ（noindex）が付く。`True` にすると外れ、各ページの正本がこのサイト自身になり、`sitemap.xml` も作られる |

検索に出すときは、`SEARCH = True` にして push したあと、Google Search Console にサイトを登録して `sitemap.xml` を送る。
