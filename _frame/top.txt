# トップの写真と動画の並び。上の行から順に出る（1行目が、ページを開いたときに最初に出る写真）。
# 1行に1つ、「ファイルの名前 | 説明」の順に、半角の | で区切って書く（| と数字と % は半角）。説明は、画面を読み上げて使う人のための文にもなる。
# 写真と動画は img フォルダに入れる。名前は半角の英数字とハイフン。
# 形は横:縦 = 8:3（例 2400×900 ピクセル）。PC では右の約3割が右のメニューの下に、左下はコピー（接合・溶接の科学で…）の下になる。
# スマホでは、真ん中の半分ほどが出る。写真は JPEG（画質80くらい）、動画は音の無い MP4（1本10MBくらいまで）。
# 3つ目からは、書かなくても構わない:
#   位置 50% 40%    写真の形が 8:3 でないとき、どこを見せるか（左から何%、上から何%）
#   スマホ 30% 50%  スマホで見せる所（書かなければ、ふつうの行は「位置」と同じ、「メニューの左」の行は真ん中）
#   10秒            その写真（動画）を出しておく秒数（書かなければ6秒）
#   メニューの左    PC で、写真を右のメニューの左に収める（前からある集合写真と、つないだ画像だけ。ぼかした背景 〜-bg.jpg も要る。8:3 で作った写真には書かない）
#   全体            「メニューの左」の範囲に、写真の全部を入れる（横に長い集合写真など）
# ここを直して push すると、トップの写真の帯が作り直される（5分ほどでサイトに出る）。
