線状加熱の体験LINE HEATING

LIVE簡易デモ　加熱した線 0 本　最大たわみ 0 Δx　一致度 -

お題
加熱する面

あそび方

  1. 板の上を指やマウスでなぞると、白い線が引かれます。
  2. その線に沿ってバーナーが動き、板を加熱します。冷えると、加熱した面の側へ板が折れます。
  3. 「裏から」に切り替えると、反対の向きに折れます。板の外をなぞると視点が回ります。
  4. お題を選ぶと、目標の形が橙の網で出ます。一致度が 80% になれば合格です。

線状加熱とは

鋼板の表面をガスバーナーで線状に加熱し、冷えるときの縮みで板を曲げる方法です。船の外板のような曲面を作るのに使われています。

※この画面は考え方を示す簡易デモです。熱伝導は陽解法、曲げは加熱した所に残る曲げのひずみだけを考えた薄板の計算で、研究室の解析コードそのものではありません。
